# 0.1.6 控制隔离／基础层5100分步对照

本版是定位实验，尚未确认修复首次位移。默认关闭，勾选“分步对照：先只隔离控制，不换动画”启用；保持“接管时刷新旧指令”关闭。全程不自动请求原生动作、不自动放行或重新隔离。

## 一轮测试步骤

1. 结束Beta和旧工具驾驶，停止旧工具的动画隔离、代码飞行及位移隔离。Reset scripts，确认菜单“狮鹫动画实验室 0.1.6”。用Beta生成新狮鹫，不开始驾驶。
2. 在实验室勾选“绑定Beta当前狮鹫”“启用状态与坐标记录”“记录原生方法前后坐标”。先保持“启用隔离播放”关闭，等约2秒，确认样本数增长。
3. 准备原生悬停：可以在旧工具的“已有动作按钮（起飞／前移／快速飞行／落地）”里，仅点击一次“悬停（地面升至固定高度）”。动作目标应显示“Beta 当前狮鹫（优先）”；不要在旧工具另行生成或开启隔离。回到实验室，等读数显示“动作：HoverWait”“飞行：true”。允许它还在升高或起伏，不必等位置完全静止。若约10秒仍不到这个状态，直接保存本轮记录，不反复请求或开关。
4. 确认“接管时刷新旧指令”关闭，勾选“分步对照：先只隔离控制，不换动画”，再勾选“启用隔离播放”。状态应为“A：只隔离控制，所有动画层零重播”。观察约2秒，留意是否已经跌落、动作是否变成FrontFall／FrontFallLanding。A不应主动显示5100或5101。如果A已经跌落，跳到第6步即可。
5. 若A仍是HoverWait，保持隔离开启，点击一次“进入B：只换基础层5100（保持隔离）”。状态应为B，基础层读数应变为Bank 0 / Motion 5100。再观察约2秒，留意是否从这里才开始跌落或出现新位移。不要中途关闭隔离、发送动作或切换挥翅。重复点击不会再次换片；本轮不能从B退回A。
6. 取消“启用隔离播放”，继续记录约2秒；再关方法跟踪、关状态记录保存。不必等落地，也不必做第二轮。反馈“A是否跌落／B是否跌落；大致从哪一步移动”，如准备阶段失败或报错，也直接保留日志。

同一轮不重新生成、驾驶或Reset。日志位于游戏reframework/data/GriffinAnimationLab_*.json，无需手抄坐标。

## 实验边界

A仅捕获原控制值、关闭FSM、RootMotion设为None、拦截精确本实例的三个FlightControl入口；基础层及附加层全部不调用changeMotion。原动画可能随引擎继续变化，A不把它固定在某帧。

B沿用A同一个隔离对象、原始控制快照和轮号；仅基础层changeMotion到Bank0/5100一次。不重播附加层、不重写FSM／RootMotion、不放行控制。普通隔离原有的附加层重播仍保留；B不复现只能说明本轮这一组合未触发，不能排除附加层或更长时序的影响。

开启前必须正在原生空中HoverWait、原FSM为true，实际基础层已离开隔离资源；记录关闭、刷新选项开启或组件归属不符时，冻结前拒绝。A/B选项及刷新选项在本轮内修改只影响下一次接管；本轮A/B内挥翅开关不换片。关记录会结束A/B并恢复控制。暂停挂起队列，取消／解绑／Reset拒绝迟到B；实例、动作管理器／FSM、Motion、飞控或驾驶归属变化停止本轮。恢复失败保留隔离状态供重试。

记录增加ab_before_controls、ab_controls、ab_before_motion、ab_motion边界及ab_stage=A/B；周期样本和方法前后快照都带阶段，保留原mode与interval语义。请求ID和实际基础层资源分别记录。新模块isolation_ab负责阶段和排队，isolation只增加不重播的控制隔离入口。入口及七模块共八个Lua，所有新开关默认关闭，不保存用户配置。

Lua54八文件语法、原状态／方法跟踪／0.1.5刷新回归，以及A全层零重播、B单次基础层写入、同轮同快照、暂停／取消／Reset／过期队列、正反实例／组件归属、记录与准备条件、换片异常、恢复失败重试和默认附加层重播回归通过。没有增加位置／碰撞体／速度／AI／着地写入；原生画面及根因判断待实机，不打verified标签。
