# 0.1.8：根应用与飞控碰撞回调只读定位

新增默认关闭“记录根应用与飞控碰撞回调（只读，需状态记录）”。控制流程保持0.1.7：本轮仍使用A/B和动作更新隔离。本版增加记录，尚未修复首次位移，画面仍移动也有用。

## 只做一次短记录

1. 结束驾驶和旧工具隔离／代码飞行／位移隔离，Reset scripts，确认实验室0.1.8。用当前Beta生成新狮鹫，不驾驶。
2. 绑定当前狮鹫，开启状态与坐标记录、原方法前后坐标记录，再开启新增“记录根应用与飞控碰撞回调”。确认样本数增长，位置入口显示4/4或保存调用对开始增长；不是4/4也保留记录，不反复开关。旧方法跟踪4/5是已知缺少Rollbacker的情况。
3. 保持隔离关闭，在旧工具“已有动作按钮（起飞／前移／快速飞行／落地）”只点一次“悬停（地面升至固定高度）”。动作目标应是Beta当前实例。等实验室读数HoverWait、飞行true，不必等位置稳定；约10秒仍未达到就直接保存。
4. 关闭“接管时刷新旧指令”，同时勾选“分步对照”和“隔离时暂停原生动作更新”，再开启隔离。A保持约2秒。
5. 保持隔离，点一次“进入B：只换基础层5100”，B保持约3秒。无需反复换片、发动作或等落地；记录会抓前后坐标。
6. 关闭隔离，继续记录约2秒；关闭新增位置入口跟踪、旧方法跟踪，最后关闭状态记录保存。不需要第二轮。

反馈记录已完成、位置入口是否4/4及有无报错即可，仍可补充画面现象。不需手抄坐标，同一轮不重新生成／驾驶／Reset。日志仍在游戏reframework/data/GriffinAnimationLab_*.json。

## 新探针范围

独立pose_trace模块复用原只读配对器，观察精确本实例FlightControl.updatePosition()、eventBeforeColliderAdjust(via.GameObject)、eventAfterColliderAdjust(via.GameObject, via.motion.ExpressionUpdate)及Character.onRootApply(via.vec3, via.Quaternion)。当前本地转储已核对签名，启用再次核对实例方法、参数数量及System.Void。FlightControl读取CachedCharacter校验；Character直接匹配当前返回角色。未知对象不转换、不读取，不解码值类型参数。

四入口全部放行原调用和原返回值；不增加原生拦截、动作请求或任何位置／速度／着地写入。采样实际动作、基础层、FSM／root、实体Universal／场景、上下文Universal、碰撞体场景坐标及A/B轮号、动作更新拦截数；记录在pose_trace中，与旧call_trace的数据、开关和Hook线程存储独立。状态及事件增加requested_enabled与修订号，区分用户刚关闭但恢复尚未执行的窗口。

每入口最高20Hz／1000配对，总上限4000；保存变化对及每秒稳定心跳，Hook内不写盘。满额只停采样，不结束动画；关闭／Reset、暂停、记录关闭、过期队列、实例／组件变化拒读或丢弃未完成配对。部分接口不可用独立报错，其他入口仍记录。调用内坐标差可缩小写入范围，仍须结合嵌套顺序判断，不能把某个包围调用直接称为唯一写入者；20Hz采样也不能排除未捕获的其他时刻。

入口及九模块共十Lua，新增开关默认关闭、不保存用户配置。当前Beta、原路线探针、旧阶段三及其他MOD保持不改。十Lua54编译、原状态／调用跟踪／刷新／A/B／动作更新隔离回归，以及新四入口正反实例、原返回、嵌套／数字历史、独立开关／数据、签名／部分归属失败、暂停／过期／Reset、限频／心跳／容量和A/B关联回归通过。已部署待实机；不打verified标签。日志、实测报告、设置、转储、备份及本地回归不入Git。
