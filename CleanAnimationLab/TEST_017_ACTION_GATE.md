# 0.1.7：暂停精确实例动作更新的A/B对照

本版新增默认关闭“隔离时暂停原生动作更新（仅A/B，下次开启生效）”。只在既有A/B中额外暂停精确当前实例的ActionManager.update；没有新增动作请求、位移／速度／着地写入。用于验证隔离期间仍执行的动作更新是否影响换片后的位移，尚未确认修复。

## 只做一轮

1. 结束Beta和旧工具驾驶、动画隔离、代码飞行及位移隔离，Reset scripts，确认菜单0.1.7。用Beta生成新狮鹫，不驾驶。
2. 实验室绑定当前狮鹫，开启状态与坐标记录、方法前后坐标记录，保持“启用隔离播放”关闭。确认样本数增长约2秒。
3. 在旧工具“已有动作按钮（起飞／前移／快速飞行／落地）”里，只点一次“悬停（地面升至固定高度）”。确认动作目标是Beta当前狮鹫；不在旧工具另行生成或开启隔离。回实验室等待动作HoverWait、飞行true，不要求位置静止。约10秒仍不到这个状态就直接保存，不反复请求。
4. 关闭“接管时刷新旧指令”，同时勾选“分步对照：先只隔离控制，不换动画”和新增“隔离时暂停原生动作更新”，再开启隔离。A观察约2秒：记下画面是否悬停、面板实际动作是否仍HoverWait，以及“动作更新隔离”拦截次数是否增长。
5. 保持隔离，点一次“进入B：只换基础层5100”。B观察约3秒，区分换片时跳一下与随后持续移动。若A已经明显跌落、报错或拦截次数一直为0，直接结束保存，不必进入B。
6. 关闭隔离，继续记录约2秒，再关方法跟踪、关状态记录保存。不必等落地，也不做关闭新增开关的第二轮；已有0.1.6记录作为对照。

反馈：A实际动作／拦截次数是否增长；B是否入口跳变、是否继续移动；关闭后画面变化。日志自动保存详细坐标，不需手抄。同轮不重新生成、驾驶、发其他动作或Reset；不切换5101。

## 作用范围与记录

新模块action_gate只挂app.ActionManager.update()；当前本地转储确认为实例方法、零参数、System.Void，启用时再次核对签名。先通过既有原生HoverWait、FSM及精确组件检查，再安装并准备Hook；A捕获控制后才开始有效拦截，B继续沿用同一个动作管理器和隔离轮。其他角色不转换、不检查、不拦截，原生返回值保持。

开关仅影响下一次A；本轮内修改不解除或新加拦截。只用于A/B，普通隔离拒绝混用，不能与悬停刷新同时开始。暂停放行原动作更新且挂起测试步骤；取消／解绑／Reset、记录关闭、实例／动作管理器／FSM／Motion／驾驶归属变化拒绝继续拦截。Hook读取异常放行并停止拦截，下一次实验验证结束A/B；关闭或恢复失败都会先撤下动作更新拦截，原隔离恢复状态保留重试。

状态记录action_gate.active／blocked／errors／last_error，方法边界另存本轮action_update_blocked计数。方法跟踪仍为只读；存在动作更新拦截时，方法Hook前后采样不能作为原ActionManager.update实际执行的证明，应同时检查拦截计数。Hook内不写盘、不请求动作、不修改坐标；原生动作与资源仍分开记录。

入口及八模块共九个Lua，新增开关默认关闭，不保存用户配置。Beta0.1.35、旧阶段三0.3.23及其他MOD不改。九Lua54编译、既有状态／方法跟踪／0.1.5刷新／0.1.6 A/B回归，以及精确正反实例、单次B、原返回、签名变化、暂停／取消／Reset／过期队列、记录／组件／驾驶变化、Hook异常放行、恢复失败重试及数字历史回归通过。已部署待实机，不打verified标签。
