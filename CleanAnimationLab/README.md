# 狮鹫动画实验室 0.1.1

当前结论：0.1.0首次隔离仍有位移；反复开关无效。用户观察到某次关闭后真正落地一次，再开启才可原地播放，但落地无法稳定复现。本版只补状态证据，没有宣布修复首次位移。

依赖：已安装NickCore（run_once行为队列）；Beta仅提供它生成的精确实例。Beta0.1.35、旧阶段三0.3.23及其他MOD保持原样。

安装：GriffinAnimationLab.lua和_GriffinAnimationLab目录一起放入reframework/autorun。五个Lua文件含入口和四个职责模块；子模块不单独启动。

所有开关初始关闭，不读取旧设置自动开启。隔离仍只关闭FSM/根位移并拦截精确FlightControl的update、lateUpdate、eventFlightUpdate；切换5100/5101保持隔离及同一轮号。取消隔离恢复原FSM/根位移，停止不恢复先前动画姿态。没有锁位置、请求落地、清速度或伪造着地。

## 本轮测试

1. 结束Beta驾驶，停止旧工具的隔离／代码飞行／玩家固定，再Reset scripts。用Beta生成并保留狮鹫，结束驾驶。
2. 展开“狮鹫动画实验室 0.1.1”，勾选“绑定Beta当前狮鹫”和“启用状态与坐标记录”。保持隔离关闭约2秒。
3. 勾选“启用隔离播放”，观察约3秒。若仍移动，取消隔离；保持记录开启约10秒，覆盖原生恢复与可能的落地过程。
4. 如果看到真正落地，再开启隔离约3秒。若一直不落地，结束本轮即可；失败过程同样有用，无需反复开关碰运气。
5. 在同一有效隔离中切换“使用挥翅5101”，确认切换没有归还原生控制。最后关闭记录保存。

记录：reframework/data/GriffinAnimationLab_*.json，默认关闭。最高20Hz、最多3000个状态样本（约150秒有效采样，实际取决于帧率）；满额不停止动画。普通帧每两秒写盘，操作事件和关闭记录时保存。没有渲染回调采样或写盘。

记录开启且已绑定时，在隔离关闭／Beta原生驾驶时也可只读采样同一实例；不会因此接管它。普通采样进入NickCore行为队列，暂停／过期队列／实例变化丢弃；开关应用前后与Reset前后另存状态快照。记录开启前的过程不能追溯，3000样本用尽后需Reset开始新日志。

每条包含原生动作、IsGround/IsFlight、SecFall、LandingProcessor地面标志、FlightControl移动向量／旧速度、Transform的Universal与场景坐标、位置上下文和碰撞体场景坐标、FSM/RootMotion及隔离轮号。飞控读数验证精确实例归属；字段失败单独记errors，不当作零或false，不停止动画。不同坐标系不可直接相减；内部向量有非零值也不能单独证明它正在写位移。菜单着地／动作显示是最近记录值。

模块职责：入口注册回调；lab.lua负责菜单／绑定／队列；isolation.lua负责原有隔离／动画／恢复；recorder.lua负责限频与保存；state_probe.lua只读状态。日志、设置、备份与本地测试工具不上传Git。

验证结果与限制见TEST_011_STATE_PROBE.md；原生读数、性能及首次位移仍需实机确认。
