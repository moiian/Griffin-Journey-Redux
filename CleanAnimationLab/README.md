# 狮鹫动画实验室 0.1.6

新增默认关闭的A/B分步对照，定位空中HoverWait接管后转跌落发生于哪个步骤。A只隔离控制，所有动画层零重播；B保持同一轮隔离，仅将基础层播放为5100一次。不自动请求悬停、不放行或重新隔离。首次位移尚未确认修复，原生效果待实机。

依赖已安装NickCore及Beta精确返回实例。入口与七个模块共八个Lua；所有开关初始关闭，不保存设置。Beta0.1.35、旧阶段三0.3.23和用户JSON不改。A/B工具本身不依赖旧工具模块；原生悬停准备可借用已有单次动作按钮。

本轮按[TEST_016_ISOLATION_AB.md](TEST_016_ISOLATION_AB.md)做一次对照：绑定并开状态／方法记录，隔离关闭时准备原生HoverWait与飞行true；关闭悬停刷新，勾选A/B再开启隔离。观察A约2秒；若已跌落直接保存，否则点“进入B：只换基础层5100（保持隔离）”，再观察约2秒。关闭隔离后记录约2秒，关闭方法跟踪和状态记录保存。不要在A与B之间发动作、关闭隔离或等落地再接管。

A/B和悬停刷新不能同时开始。阶段在本轮内保持，修改A/B选项只影响下一次开启；挥翅选择在A/B内不生效，B不能退回A。记录关闭、实例／组件／驾驶归属变化会结束实验；暂停挂起，取消／Reset拒绝迟到操作，恢复失败保留状态重试。

ab_stage与四个阶段事件进入状态及方法前后记录。只读状态记录最高20Hz／3000样本，方法跟踪每入口20Hz／1000对，满额不停止动画。日志在游戏reframework/data，原始日志、实测分析、设置、转储、备份和本地回归工具不入Git。

普通5100／5101隔离、默认关闭的0.1.5悬停刷新及原恢复路径保留，历史说明见TEST_015_REFRESH_SEQUENCE.md等版本测试文档。Lua54及新旧离线回归通过。没有新增位置、碰撞体、速度、AI或着地写入；A/B只用于定位，不能把离线通过当作无位移修复。
