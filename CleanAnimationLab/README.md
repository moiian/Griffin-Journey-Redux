# 狮鹫动画实验室 0.1.0

目的：单独验证Bank0/5100滑翔和5101挥翅的隔离播放。没有驾驶、自动生成、AI保护、玩家搬移、相机或原生动作请求。不能据此宣称首次播放的残余位移已解决。

依赖：已安装NickCore（使用run_once行为阶段队列）；Beta仅用于明确取得它生成的精确实例。没有复制NickCore生成逻辑，也不依赖旧阶段三实验工具。

安装：GriffinAnimationLab.lua和_GriffinAnimationLab目录一起放进reframework/autorun。子模块不在autorun根目录单独启动。

所有开关初始关闭，不读取设置自动启用。仅启用隔离时安装精确FlightControl Hook；关闭后原生调用放行。切换5100/5101不恢复FSM或根位移，不重新保存已经修改过的原始状态。不存在3秒冷却。未绑定、未加载资源、正在驾驶时拒绝启动。停止不恢复先前动画姿态，恢复原FSM/根位移控制。

测试步骤：
1. 在旧工具中停止隔离／代码飞行／玩家固定。用Beta生成狮鹫，结束驾驶，保留狮鹫。不要同时用旧工具操作同一只狮鹫。
2. 展开“狮鹫动画实验室 0.1.0”，勾选“绑定Beta当前狮鹫”。
3. 如需专属日志，先勾选“启用坐标记录”，再勾选“启用隔离播放”。默认5100。观察首次播放是否仍位移。
4. 勾选／取消“使用挥翅5101”，来回切换。隔离保持开启，不用先停止。观察切换是否引起落地或飞走。
5. 取消“启用隔离播放”才会恢复原生控制。取消绑定也停止隔离。脚本Reset恢复原状态，所有开关重置为关闭。

记录位于reframework/data/GriffinAnimationLab_*.json。最多3000个坐标样本（约10分钟），达到上限不停止播放；两秒写盘，开关记录和停止隔离时保存。日志不上传Git。

模块职责：入口仅注册回调；lab.lua负责菜单、绑定及队列状态；isolation.lua负责精确实例Hook/动画/恢复；recorder.lua只做可选记录。后续位移、输入、镜头分别新增模块，并保持默认关闭。

检查状态：Lua54语法和模拟状态测试通过与否见交接记录；原生实机效果需要测试。Lua pcall不能拦住原生访问异常。
