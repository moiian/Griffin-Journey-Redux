# 狮鹫动画实验室 0.1.2

0.1.1完整实测已经确认：首次隔离仍移动，FSM=false、RootMotion=0时原生动作仍进入跌落／落地；原生动作进入Wait后再次隔离可稳定播放。被测飞控移动向量均为0。本版增加实际基础层动画读数与原生方法前后只读跟踪，定位剩余位移路径，尚未修复首次隔离。

依赖：已安装NickCore（run_once行为队列）；Beta提供其生成接口返回的精确实例。Beta0.1.35、旧阶段三0.3.23及用户设置不改。

安装：GriffinAnimationLab.lua和_GriffinAnimationLab目录一起放入reframework/autorun。共六个Lua文件：入口、lab、isolation、recorder、state_probe、call_trace；子模块不单独启动。全部开关默认关闭。

隔离措施保持原样：关闭原动作FSM／根位移，并拦截精确FlightControl.update、lateUpdate、eventFlightUpdate；切5100／5101不退出隔离。取消隔离恢复原FSM／根位移，停止不恢复先前动画。新探针不写位置、不请求落地、不清速度、不改变原生方法返回值。

## 0.1.2测试步骤

这轮采集新增的“方法调用前后”证据。上一轮0.1.1完整日志继续有效，不需要补录旧版。

1. 结束Beta驾驶，停止旧工具的隔离／代码飞行／玩家固定；Reset scripts。确认菜单显示“狮鹫动画实验室 0.1.2”。用Beta生成一只新的狮鹫，本轮不要开始驾驶。
2. 勾选“绑定Beta当前狮鹫”、“启用状态与坐标记录”和新增的“记录原生方法前后坐标”。确认状态样本增长，方法跟踪显示“5 / 5个入口”。保持隔离关闭约2秒。若入口数不足5，也保留本轮日志和菜单读数，不必反复重置。
3. 勾选“启用隔离播放”，保持滑翔5100约3—4秒，观察首次是否位移。然后关闭隔离，状态记录和方法跟踪都保持开启，等原生变化最多约10秒。
4. 若自然落地并站稳，再开启隔离约3秒；保持隔离，勾选“使用挥翅5101”约3秒。若10秒内没有落地，跳过这一步，直接保存失败过程，不反复开关碰运气。
5. 关闭隔离，再留约2秒；依次关闭“记录原生方法前后坐标”和“启用状态与坐标记录”。最后两个关闭动作会保存日志。本轮中途不要Reset、删除／重新生成或开始驾驶。

反馈首次是否移动、落地后是否静止、切5101是否静止，以及“方法跟踪”显示几个入口。无需手抄坐标或卡落地瞬间。日志仍在reframework/data/GriffinAnimationLab_*.json。

## 记录与限制

原状态记录最高20Hz、3000样本，绑定后隔离关闭时也记录；应用／Reset前后快照与原生字段继续保留。新增base_layer包含实际读取的Bank、Motion ID、帧与启用状态；clip／requested_clip仅代表最后请求的资源。字段失败独立记errors，不当作0或false。

方法跟踪另有默认关闭开关，需要绑定和状态记录同时开启才安装／启用Hook。仅匹配从该角色取得并核对归属的对象，不扫描同ID角色，不把无关Hook参数转换为托管对象。五个入口为ActionManager.update、AdjustTerrain.update、AdjustTerrain.updateSubPosition、CharacterPosRotAdjuster.writeToTransform、CharacterPosRotContextRollbacker.updateAndRollbackIfNeeded。

日志call_trace.methods记录接口可用性、命中、采样配对、保存、变化、错误及满额丢弃计数；call_trace.pairs包含调用顺序号、前后快照和同坐标系距离。每入口最高20Hz、最多1000个采样对；采到位置／动作／基础层资源／FSM／RootMotion变化时保存，否则每入口每秒保存一个稳定调用对。上限合计5000对；达到上限只停止该入口采样，动画和原生调用继续。

跟踪覆盖原生、隔离、恢复三个状态。取消隔离不会自动结束跟踪；关闭跟踪／状态记录／绑定，实例或模块变更、过期队列、暂停及Reset会停止读取或丢弃未完成调用对。普通帧每两秒保存、操作事件即时保存；Hook内不写盘，无渲染回调采样／写盘。Hook安装后默认放行；观测前后均保持原调用和返回值。

采样可能漏掉短暂调用，零变化不能排除该方法；外层调用可能包含子调用，前后变化不能单独证明唯一写入者。嵌套前后顺序号用于辨认包围关系。不同坐标系不能直接相减。原生性能、虚调用／内联是否命中、实际字段与首次位移根因仍需实机；本版不打verified标签。

模块职责：入口注册回调；lab菜单／绑定／队列；isolation原隔离／动画／恢复；recorder限频／保存；state_probe数值只读；call_trace精确原生调用配对。日志、设置、备份、测试运行时和转储不入Git。
