# 狮鹫动画实验室 0.1.3

首次隔离仍会受接管前原生行为影响。0.1.2实测确认实际5100持续播放仍移动，原生动作结束后重开稳定；四个已生效方法入口未定位到调用内位移。本版增加默认关闭的接管前原生动作／AI重置实验，尚未确认修复。

依赖已安装NickCore及Beta提供的精确返回实例。安装入口GriffinAnimationLab.lua与_GriffinAnimationLab整个目录，共七个Lua文件。所有开关初始关闭；Beta0.1.35、旧阶段三0.3.23、其他MOD和用户设置不改。

## 本轮测试

这次只检验接管前单次重置能否让首次隔离直接静止，不需要重复旧版对照。

1. 结束Beta驾驶，停止旧工具隔离／代码飞行／玩家固定，Reset scripts，确认菜单为0.1.3。用Beta生成新的狮鹫，不驾驶，也不等它完成原有行为或落地。
2. 勾选绑定、状态与坐标记录，先记录约2秒；勾选新增“接管前重置原生任务（实验，每轮一次）”。方法跟踪可继续开启；此角色上4／5入口是已知现象，回滚模块缺失不影响本实验。
3. 首次勾选隔离，保持5100约5秒。确认“原生重置”显示1次调用／1次返回，观察是否仍朝原目标移动、瞬移或跌落。调用返回仅表示函数返回，不代表修复成功。
4. 若已经原地播放，保持隔离切到5101约5秒；计数应仍为1次。若仍移动或提示重置失败，直接结束并保存，不用等落地后再试。
5. 关闭隔离，继续记录约2秒，再关方法跟踪（如开启）、状态记录。反馈首次是否静止、是否有入口位置跳变／跌落、切片情况及重置调用／返回数。

本轮中途不重新生成、驾驶或Reset。日志仍在reframework/data/GriffinAnimationLab_*.json，记录关闭会保存。用户不必手抄坐标。

## 选项与行为

新实验每轮首次接管只请求一次resetActionAndAI：ActionName=Wait，IsResetAI=true，不重置Catch／Caught。需要状态记录开启；原FSM已经关闭时拒绝实验。隔离中修改重置开关不会立即运行，也不重播动画，只影响下一轮接管。切5100／5101不重置。

先保存原FSM／RootMotion，再构造并调用真实选项对象；原生重置准备期飞控回调放行，返回后才进行原有隔离。重置前后分别记快照，日志mode=preparing。失败退出并恢复控制，恢复失败保留重试；不会每帧重复重置。停止只恢复原FSM／RootMotion，不重新启动被取消的任务。

旧隔离仍是关闭FSM／根位移与精确FlightControl三入口拦截；没有新增坐标、碰撞体或速度写入，也不伪造着地。原生重置可能自身改变动作／位置，必须实测；一次原生调用返回不足以证明任务已经结束。

状态记录保留20Hz／3000样本、原生关闭阶段采样、实际基础层Bank／Motion ID／Frame／Enabled及字段独立错误。clip是最后请求编号，base_layer才是实际读数。

方法跟踪仍为独立默认关闭选项：精确ActionManager、AdjustTerrain两个入口、PosRotAdjuster写回及可用的Rollbacker。每入口20Hz／1000采样对，变化保存、稳定每秒心跳；Hook内无写盘、达到容量不停止动画。原生、隔离、准备／恢复阶段均可记录。模块缺失单独记错误，不作零变化证据；采样／包装入口限制与嵌套调用不能单独证明唯一写入者。

模块按职责拆分：入口、lab、isolation、recorder、state_probe、call_trace、task_reset。日志、转储、设置、备份和本地测试工具不入Git。实机待验收；离线检查和接口说明见TEST_013_TASK_RESET.md，前两版说明保留。
