# 狮鹫动画实验室 0.1.4

本版把“隔离中请求新动作→短暂解除隔离→新动作进入→重新隔离”做成默认关闭的悬停刷新实验。0.1.3同步resetActionAndAI返回后立即冻结未解决首次位移，已撤下该实验模块。0.1.4是否能稳定复现手动流程仍待实机。

依赖已安装NickCore及Beta提供的精确返回实例。入口GriffinAnimationLab.lua与_GriffinAnimationLab六个模块，共七个Lua文件。所有开关初始关闭；不保存设置。Beta0.1.35、旧阶段三0.3.23及其他MOD保持原样。

## 本轮测试

1. 结束Beta驾驶，停止旧工具隔离、代码飞行及玩家固定。Reset scripts，确认菜单0.1.4，用Beta生成新狮鹫。不驾驶，不等原任务完成或落地。
2. 勾选“绑定Beta当前狮鹫”和“启用状态与坐标记录”，记录约2秒。勾选“接管时刷新旧指令（悬停后重新隔离，实验）”。本轮方法跟踪可以关闭。
3. 首次勾选“启用隔离播放”，保留滑翔5100。无需手动发悬停或开关隔离。工具会自动请求一次HoverWait、短暂放行，确认原生动作及基础层资源进入后重新隔离。
4. 看“悬停刷新”是否到达“1次请求／1次返回／1次确认”。从完成确认起观察5100约5秒，分别记录刷新过程是否有明显移动、确认后是否仍持续移动。计数只证明流程走完，不证明无位移。
5. 若已稳定，保持隔离切5101约5秒，计数应仍为1。若仍移动或刷新报错／超时，直接结束并保存，不用等待落地或反复开关。
6. 关闭隔离，继续记录约2秒，再关闭状态记录保存。反馈请求／返回／确认数、刷新阶段及确认后的移动、切片效果。无需手抄坐标。

保持本轮同一实例，中途不重新生成、驾驶或Reset。原生悬停进入时可以产生位移；本版不锁坐标。日志在reframework/data/GriffinAnimationLab_*.json。

## 刷新时序与恢复

只在新隔离轮且实验已勾选时运行一次。先按原流程隔离并播放所选资源，在FSM关闭时向精确当前ActionManager请求HoverWait，再恢复首次捕获的FSM／RootMotion并放行本实例的FlightControl。保留同一隔离轮及原始控制值，期间日志mode=refreshing。

请求返回后至少经过一次实际UpdateBehavior；在NickCore的后续行为队列中同时观察CurrentAction.Name=HoverWait、启用的基础层已离开Bank0/5100或5101，才重新冻结并播放当前选择。动作名变化或函数返回均不能单独当作确认，不依赖固定等待后无条件重开。

未确认超过3秒有效行为时间则退出隔离并恢复控制，不自动重试；暂停不计时、不确认。取消隔离、解绑、实例或组件变化、驾驶接管、关闭记录、请求异常及Reset均阻止迟到的重新隔离。恢复失败保留原恢复状态供取消隔离重试。隔离中切片不请求新动作；切刷新选项只影响下一轮。

原FSM已关闭或未开启记录时拒绝实验。取消与退出不撤销已经交给引擎的HoverWait，也不恢复此前原生任务。没有新增实体、碰撞体、速度、AI或着地写入。

## 记录和模块

状态记录仍为20Hz／3000样本，原生关闭阶段继续记录，满额不停止动画。base_layer是实际资源读数；clip是请求编号。刷新各边界另外保存快照、请求／返回／确认计数、有效时间及行为序号；等待轮询不逐帧写事件。

方法跟踪独立默认关闭，保留原0.1.2的精确对象、只读前后配对及限频／容量约束；模块缺失单独报错。此次刷新不依赖方法跟踪。
