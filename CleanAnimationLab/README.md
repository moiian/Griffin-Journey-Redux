# 狮鹫动画实验室 0.1.5

本版修正0.1.4自动刷新与手动操作的时序差异。默认关闭；原生效果待实机。0.1.4仅在一次回调中请求／放行，随后把短暂HoverWait读数当作立即复隔离条件，未解决首次位移。本版分别执行隔离、请求处理、放行及原生稳定观察，不要求最终播放悬停。

依赖已安装NickCore及Beta精确返回实例；入口与六个模块共七个Lua。所有开关初始关闭，不保存设置。Beta0.1.35、旧阶段三0.3.23和用户JSON保持原样。

## 本轮测试

1. 结束Beta驾驶及旧工具隔离，Reset scripts，确认菜单0.1.5。用Beta生成新狮鹫，不驾驶，不等旧任务完成或落地。
2. 绑定当前狮鹫，开启状态与坐标记录约2秒，再勾选“接管时刷新旧指令”。方法跟踪可关闭。
3. 首次开启隔离，保留5100。无需手动发动作或开关。工具应依次显示隔离等待、请求处理、解除隔离观察，最后“已完成复隔离”，计数1次请求／1次返回／1次复隔离。
4. 分别观察刷新过程是否明显移动、复隔离后约5秒是否持续移动。最后实际原生动作允许是跌落／落地／Wait，不要求看到持续悬停。
5. 若已经稳定，保持隔离切5101观察约5秒，计数应仍为1。若仍移动、超时或报错，直接保存，不用反复开关或等落地后重试。
6. 关闭隔离，继续记录2秒，再关闭记录保存。反馈三个计数、刷新过程移动与复隔离后移动、切片结果。无需手抄坐标。

本轮保持同一实例，不中途驾驶、重新生成或Reset。日志在reframework/data/GriffinAnimationLab_*.json。

## 流程与判据

进入隔离后至少经过一次实际UpdateBehavior，才向精确ActionManager请求一次HoverWait。请求后继续保持FSM关闭和飞控隔离，处理两个实际行为更新；之后恢复首次保存的FSM／RootMotion，放行本实例飞控。不在一次回调内连续完成请求和解除。

放行后读取实际原生动作、基础层资源及Universal位置。基础层必须已离开Bank0/5100、5101；同一动作与资源连续至少0.3秒且至少3次实际行为观察，整个窗口位置距固定起点不超过1厘米，才重新隔离并播放当前选择。动作／资源变化或累计位置越界重开观察窗口；不以逐帧小差值接受持续漂移。允许原生自然转为跌落、落地或Wait，没有强制着地或额外落地请求。

这只是有限观察窗口，不证明原任务已清空或以后一定静止。UI改称“复隔离”计数，不再把瞬态HoverWait叫作成功确认。流程总计超过5秒有效行为时间仍不稳定则退出隔离并恢复，不自动重试。

暂停挂起行为计时；取消、解绑、Reset、记录关闭、过期队列、实例／模块／驾驶归属变化拒绝迟到操作。原FSM为false或未开记录时拒绝实验。原控制值及隔离轮保留，切片不重新请求；隔离中改变刷新选项只影响下一轮。恢复失败保留状态供重试。退出不撤销已提交的新动作，也不恢复此前原生任务。
