This revision changes only the insertion/sampling phase to post-`LateUpdateBehavior`. It retains the same fixed +6 m/s addition, current-position incremental writes, Transform/context/controller synchronization, unmodified rotation/action/navigation, two-second baseline, six-second addition and two-second recovery. No continuous rendering-position writes or absolute pinning are added. LateUpdateBehavior is an existing application callback used by installed native control scripts; this experiment registers its own callback and does not modify those scripts.

No field writes occur at these checkpoints.
