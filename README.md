# Griffin Journey Redux

Dragon's Dogma 2 REFramework Griffin flight experiments. Requires installed NickCore EnemySpawner and run_once; dependencies are not bundled.

Only the two first-party scripts and their history/test documentation are tracked. Logs, settings, game dumps, and third-party reference mods remain outside this repository.

Historical commits named `Import archived ...` were reconstructed from existing script snapshots on 2026-10-11; their commit dates are import dates, not original development dates. Consult VERSION_HISTORY.md for runtime validation and known failures.
