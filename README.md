# 最终操控方案草案（尚未实现）

用户目标：左摇杆转向与小幅高度修正，RB/LB大幅升降；RT直达冲刺，LT逐档减速；以既有原生动作组合呈现不同速度手感。

| 状态 | 操作与动作建议 |
| --- | --- |
| 3档冲刺 | 目标导向飞行；左摇杆左右转向，上下只作小幅修正（可先试±8—12°）；RB按住大角度爬升，LB按住大角度俯冲，松开回到摇杆修正；两肩键同时按抵消。RT单次按下切入并保持，不要求持续扣住。 |
| 2档惯性调整 | 从3档按一次LT进入目标高度前移；回中继续前移以表现惯性，左/右/后输入请求相应目标高度平移动作；斜向先选择主轴，避免逐帧抢动作。升降肩键可改变导航高度目标，但本档原生动作的响应需另测。 |
| 1档精细定位 | 再按LT进入；有输入请求空中悬停向目标移动，并恢复围绕头部的目标操控；回中请求0档悬停，但保留精细模式，重新拨杆即可微移。建议允许水平四周定位，后方追踪能力仍需专门验证。 |
| 0档停留动作 | 作为1档回中的实际动作，使用已验证原位悬停；不把它当成另一个必须手动进入的操作模式。 |

保持A起飞/降落，允许跨阶段。LT按下沿触发一次降档，按住不连降；RT从任意档直接回3档。动作切换按意图变化提交，不能逐帧重播。界面显示当前操作档位及动作，例如“1档·悬停”，避免回中后忘记应如何继续操控。

大角度升降首先是导航引导，不能据此保证能量守恒、真实速度增益或固定角速度。“惯性”首先由前移动作呈现，不声称已建立统一物理速度模型。先测完整状态切换，再加入动画过渡、输入平滑或能量系统。保留头部球面、Hip显示、头部镜头和作用域恢复各自独立。
