# 狮鹫旅程 Redux — Beta 0.1.27

需要已安装NickCore EnemySpawner及run_once。本脚本直接调用其生成接口，不附带或修改NickCore、OJR、LMD及Hotkeys。

## 开始使用
Reset scripts 后展开“狮鹫旅程 Redux”→“一般设置”，点击“一键生成狮鹫”，等待就绪后“开始驾驶”。默认仅Hip头顶显示和头部镜头跟随；生成后自动启用友方、跳过思考、防坠落及冻结FSM选项，FSM在开始驾驶时冻结，结束时恢复。

若飞行目标失控，点击“让狮鹫听话”重新选取玩家目标。它不保证修复所有可能的失控原因。

## 默认操作
| 动作 | 手柄 | 键盘 |
| --- | --- | --- |
| 开始／结束驾驶 | 默认未绑定 | F／X |
| 起飞（仅地面） | A | Space |
| 冲刺／3档 | RT | 左Shift |
| 减速／降档 | LT | 左Ctrl |
| 爬升／悬停 | RB | E |
| 俯冲／降落 | LB | Q |
| 转向／升降 | 左摇杆 | WASD |
| 让狮鹫听话 | 默认未绑定 | H |

3档为目标导向飞行，1/2档RB悬停、LB降落。2档左摇杆前推请求一次“朝目标飞行”，保持输入不重复；需要中途停下时按RB。回中仍为目标高度前移惯性，无自动一秒截断。LT逐次3→2→1。按键设置可重新录入手柄、键盘及鼠标按钮；支持清除和恢复默认，录入先松开再按新键。物理左摇杆保留为连续方向输入。

## 设置
- 一般设置：召唤、开始、结束、删除、应急重新锁定目标；完整同步／仅Hip头顶为互斥模式，默认仅Hip。
- 飞行设置：转向灵敏度、导航球面半径、回中高度及肩键升降角度。
- 镜头设置：头部位置跟随、3档水平转向跟随、距离、FOV、跟随速度和右摇杆接管阈值。上下镜头自动跟随已删除。
- 座位预设：玩家、随从及正在同行的NPC分别配置头部／颈部骨骼与上下／前后／左右偏移，直接修改当前布局并自动保存，切换一起应用。正常预设从[2]开始，轮询跳过[1]，下拉框默认隐藏[1]，DEBUG可显示并手动预览；至少保留一个正常乘坐预设。名单顺序决定乘客座位，默认3个槽并随当前人数增加。各座位可关闭自动携带。
- 按键设置：动作／手柄／键鼠布局，点击当前按键录入；重复绑定会提示。
- DEBUG：默认折叠，保留跳过思考、防坠落、FSM、旧导航距离等诊断选项。开启显示预设[1]后，在座位列表选择[1]并编辑位置。随从／同伴NPC的Transform、位置上下文和碰撞体始终使用[1]中各自的pawns／companions座位参数；选[1]时Hip也使用各自的[1]参数，选[2+]时仅Hip切到各自的正常座位。玩家Transform始终由摇杆导航控制，玩家Hip跟随当前预设。

## 本轮限制与记录
用户实测肩键角度超过59°曾出现黑屏，可能与玩家过快坠落有关，根因尚未确认。当前默认和最大值均为59°，旧69°等值加载时会截断；这不代表已证明59°在所有场景绝对安全。

日志确认自动跳过思考曾因DecisionModule mismatch关闭。本版保留原实例检查并自动重试，等待模块就绪，不再因单次初始化不匹配永久关掉。DEBUG区会显示“等待模块就绪”或“已生效”，不把等待当作生效。

设置、按键和预设保存在游戏reframework/data/GriffinFlightBeta_Settings.json；日志沿用GriffinFlightBeta_*.json，均不上传Git。脚本不查Character ID接管其他狮鹫。

游戏暂停菜单只暂停驾驶更新，保留玩家、FSM及镜头接管，关菜单后继续，菜单期间飞行热键不生效。REFramework菜单在游戏未暂停时仍允许摇杆驾驶。

座位跟随所选骨骼世界位置；开启角色身体倾斜跟随时，偏移按狮鹫身体俯仰计算，关闭则保持水平/竖直。暂不跟随头颈骨骼自身旋转或身体侧滚。建议颈部座位先选靠肩膀的颈根，以减少头部摆动；仍需实机选定具体骨骼和偏移。

开始驾驶自动接管可用乘客并冻结FSM；结束驾驶、关闭某个座位、确认NPC结束同行或脚本重置后恢复捕获的原位置和FSM。防坠落开关覆盖玩家与当前精确接管乘客；未携带和释放角色不拦截。NPC只通过已验证的isAccompanyPLParty(app.Character)确认当前同行，普通路人不携带。乘客控制新增原生效果待实机。

友方名单定期刷新当前有效随从／同行NPC实例，避免仅依赖生成时的旧引用；实际远距离重新敌对是否完全解决尚待验证。

玩家／乘客座位新增Look At X左右面向、Z前后面向，以狮鹫前方(0,1)为基准，数值可自行调。新增角色身体倾斜跟随开关（默认开）及倾斜修正角（默认0）；修正角只影响朝向，不移座位。参数随预设保存与切换，镜头没有新增上下旋转。

已移除玩家和乘客逐帧跌落重置：改在首次固定、切换预设、播放动画与释放恢复位置时各一次；DEBUG实体校正变化补一次乘客重置。位置/碰撞体仍每帧同步。

座位偏移全0表示参考点在锚定骨骼上，显示Hip仍保留原角色姿态偏移，不代表Hip骨骼与锚点完全重合。


## 乘客保护与动作动画（0.1.23）

开始驾驶后，落座随从／同行NPC默认有伤害拦截；落座随从另加自动传送／丢失处理拦截，DEBUG可对照关闭。仅作用于当前接管实例，离座立即解除，不给玩家增加全局无敌。原坠落死亡请求拦截保留，日志按角色／座位区分计数；随从消失刷新是否解决待实机。

DEBUG“显示预设[1]（仅手动调试）”默认关闭；开启后[1]出现在座位列表，允许手动预览。实体偏移在座位列表选[1]后编辑，普通轮询／热键仍跳过[1]，关闭显示时回到上次正常座位。

玩家、随从与同行NPC座位新增动作名称及播放动画按钮，例如SitOnChairActions。留空不自动请求；保存后在落座／切换预设时请求一次。沿用牛车动作节点方式：临时开启FSM，请求动画，下一行为帧冻结；不含Motion ID、Bank ID或随机动作。播放失败提示并恢复冻结；离座恢复捕获的原FSM。

本次离线编译／回归通过；具体姿势与乘客长期飞行稳定性待实机。

## 座位编辑与保存（0.1.24）
菜单沿用OJR顺序：当前生效预设 → 当前布局 → 新增／删除 → 名称 → 玩家参数 → 各随从／同行NPC。坐标采用X左右、Z前后、Y高度拖动输入。相机距离/FOV在当前布局的玩家参数内。修改立即保存；不再需要“保存／另存／重命名”按钮。新增复制当前布局，删除需确认，最多15项且至少保留一个正常布局。普通暂停时切换排队，继续游戏后应用；照片模式允许立即应用座位显示。

首次加载一次性迁移旧版未写回预设的当前编辑值；后续以预设数据为准。原JSON已在升级前本地备份。保存失败会在界面显示，不再静默假装成功。[1]只通过DEBUG显示后手动选择，不参与正常轮询。新菜单与保存逻辑离线回归通过，需实机验收。

## 独立实体锚点（0.1.25）
预设[1]与其他预设一样显示玩家、每位随从和同行NPC的参数树。每名乘客的真实位置固定读取自己在[1]中的参数，互不共用；正常预设切换只改变各自Hip。预设[1]的玩家参数只控制玩家Hip，不改变摇杆导航目标或其他乘客实体。

升级时将原共用坐标一次性复制为各乘客独立的初始值，后续逐人修改、自动保存并保留到重载。旧版[1]乘客字段此前并未用于实体定位，因此迁移时以原实际共用实体坐标为起点，正常座位预设不变。缺少的新乘客槽独立初始化。[1]仍由DEBUG显示，不参与轮询。

## 照片模式（0.1.26）
进入照片模式后继续保持玩家及乘客的Hip座位显示；可在REFramework菜单调整或切换预设，立即更新显示并自动保存。沿用OJR的原生照片模式标记，骨架更新外增加渲染前的座位显示更新，支持暂停时不运行骨架更新的情形。

照片模式暂停驾驶输入、实体/碰撞体同步、AI更新和动画请求；不会通过照片模式开启新动作。动画请求保留到恢复游戏。相机仍交给原生照片模式，不写入Beta镜头FOV、距离或自动转向。普通暂停菜单维持原等待恢复行为。

## 普通菜单与过渡帧座位保持（0.1.27）
普通暂停菜单也继续保持玩家及乘客Hip的显示位置，避免进入菜单后先回到前方实体锚点、打开照片模式又移回座位。渲染前的显示更新覆盖每个驾驶帧，以应对暂停标记尚未变化但骨架已被菜单重置的过渡帧，仍沿用已验证Hip捕获/恢复管线。

真实Transform、位置上下文、碰撞体继续各自使用预设[1]，不与Hip合并。暂停中不恢复飞行、AI、FSM或碰撞体更新。普通菜单中的预设切换仍排队到继续游戏；照片模式允许立即应用。模拟确认过渡帧和菜单内模型坐标保持，但斗篷物理的实际稳定性仍需游戏验证。
